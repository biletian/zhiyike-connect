# Contributing · 参与

Zhiyike (知一刻) is a free, read-only desk. This repository holds the MCP entry, the Skill package, and the RSS mirror. Issues and pull requests stay on those doors.

本仓库只处理与公开 MCP、Skill 和 RSS 镜像有关的问题与改动。

## Open an issue · 开 Issue

Use a template in [`.github/ISSUE_TEMPLATE`](.github/ISSUE_TEMPLATE).

- **Bugs.** The site, MCP, Skill, or RSS misbehaves. Open [Bug / 问题反馈](.github/ISSUE_TEMPLATE/bug_report.md) and fill in where, steps, expected, actual, and the client version.
- **Install, MCP, and Skill.** A saved URL is connected only when the client lists the six read-only tools. The Skill needs Python 3.10+ and the official zip. If that fails, use the bug template. A usage question can go to [Discussions](https://github.com/biletian/zhiyike-connect/discussions).
- **Suggestions.** A small improvement to the same doors. Open [建议 / Feature request](.github/ISSUE_TEMPLATE/feature_request.md) with what you want and why.

请勿在公开问题中提交密钥、服务器登录信息、个人数据或未公开内容。详见 [SECURITY.md](SECURITY.md)。

## Pull requests · 拉取请求

Follow [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md): what changed, why, and what you checked. Leave out keys and personal data.

## What we do not accept · 不接受

- Paid promotion or sponsored placement.
- Brand changes, including the 知一刻 name or mark.
- Unrelated ads, or links that are not about the public site, MCP, Skill, or RSS.

付费推广、品牌改动，以及与这些公开入口无关的广告，都不收。
